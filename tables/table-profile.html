Profile description schema
Ontology Property name Datatype Cardinality Description
RDF rdf:type IRI 1 The type of the profile. The value MUST be prof:Profile.
DC terms dcterms:title rdf:langString 1..* Name of the profile with the language tag.
dcterms:description rdf:langString 0..* Description of the profile with the language tag.
PROF prof:isProfileOf IRI 0..* The specifications or base profiles that this profile constrains, e.g., DCAT 3 or a community profile of it.
prof:hasResource prof:ResourceDescriptor 1..* The resources of the profile. At least one resource descriptor MUST have the role role:validation; its prof:hasArtifact is the IRI of the metadata schema in SHACL, its dcterms:conformsTo SHOULD be the SHACL specification and its dcterms:format SHOULD give the media type of the artifact.
